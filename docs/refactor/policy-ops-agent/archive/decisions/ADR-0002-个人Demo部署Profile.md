# ADR-0002：个人Demo部署Profile

- 状态：Accepted
- 日期：2026-08-30
- 决策者：用户与Agent
- 影响阶段：Stage 04、05、07

## 背景

当前项目是个人展示/试用，不是商业生产。目标服务器为4核4GB，总用户约100以内、并发不超过5。原计划中的企业级RPO/RTO、SLA和完整本地文档AI流水线会增加不必要成本。

## 决策

- 当前部署等级为Personal Demo，不承诺SLA、RPO或RTO。
- 采用单机Docker Compose和低并发后台任务。
- 每日数据库/对象离机备份，保留14天，公开演示前完成一次恢复验证。
- Future Production作为升级Profile保留，但不属于当前DoD。

## 后果

- 优点：与个人项目资源和维护能力匹配。
- 缺点：单机故障会中断服务，恢复时间不承诺。
- 约束：OCR、Embedding和Rerank外部化；后台任务并发固定为1。

## 复审触发

并发持续超过5、总用户显著超过100、个人资料成为正式业务档案、需要SLA/RPO/RTO或需要多Worker并发时复审。
