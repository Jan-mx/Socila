# PolicyOps政策来源

> Author: Jan
> Status: Active
> Updated: 2026-09-01

## 用途

本目录保存PolicyOps允许自动采集的官方政策来源和来源管理规则。

## 文件

| 文件 | 用途 |
| --- | --- |
| `official-source-registry.md` | 国家、上海、广东和四川官方域名白名单 |

## 规则

- 只有注册表中的来源允许自动抓取。
- 新增域名前必须确认发布机关、地区、入口和内容类型。
- 重定向后的最终域名仍需通过白名单。
- 非官方来源只能人工参考，不能自动成为可发布政策证据。
