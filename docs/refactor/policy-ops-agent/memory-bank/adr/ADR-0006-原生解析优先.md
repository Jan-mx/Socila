# ADR-0006：原生解析优先，Docling仅离线辅助

- 状态：Accepted
- 日期：2026-08-30
- 影响阶段：Stage 05

## 背景

完整Docling流水线在复杂PDF上可能占用数GB内存，不适合4核4GB服务器常驻。HTML、Office、JSON和文本PDF已有更精确、资源更低的原生解析路径。

## 决策

- HTML使用httpx+lxml，DOCX使用python-docx，XLSX使用openpyxl只读模式。
- JSON使用json/ijson，Markdown/TXT使用行式解析，文本PDF使用PyMuPDF逐页提取。
- 扫描和复杂视觉页面使用远程PaddleOCR-VL-1.5。
- Docling只在开发机离线处理特殊布局或作为比较工具，不在Demo服务器常驻。

## 后果

- 降低内存和GPU要求，保留原始数据类型。
- 不同格式需要适配器和统一DocumentTree映射。
- `.doc`、`.xls`和超限文件需在开发机预转换。

## 复审触发

服务器升级到至少8GB、需要高复杂布局批处理或原生适配器无法满足质量门禁时复审。
