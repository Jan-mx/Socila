# PolicyOps质量门禁

## 文档用途

定义Stage 05/06的RAG、OCR、引用和影响分析最低质量。实现Agent不得自行降低阈值；降低必须新增ADR并获得用户批准。

## RAG预设门禁

| 指标 | 最低值 | 说明 |
| --- | ---: | --- |
| Context Precision | 0.85 | 检索上下文中真正相关内容比例 |
| Context Recall | 0.90 | 标注证据被检索覆盖的比例 |
| Faithfulness | 0.95 | 回答声明能被上下文支持的比例 |
| 引用覆盖率 | 100% | 每个政策事实和草案字段都有引用 |
| 错地区混入率 | 0 | 地方政策不得跨地区污染 |
| 错生效日期混入率 | 0 | 不得返回目标日期无效版本 |
| 受影响规则召回率 | 0.90 | 历史政策变化标注集 |

上述是Personal Demo预设门禁。Stage 05可基于黄金集提高阈值；任何降低都必须记录原因、影响、补偿措施和用户批准。

## OCR预设门禁

| 指标 | 最低值 | 处理方式 |
| --- | ---: | --- |
| 字符准确率 | 95% | 低于阈值的页面进入人工校对 |
| 文号准确率 | 100% | 不一致即`needs_review` |
| 日期准确率 | 100% | 不一致即`needs_review` |
| 金额/比例准确率 | 100% | 不一致即`needs_review` |
| 表格单元格准确率 | 90% | 关键参数表必须人工确认 |
| 页面完整率 | 100% | 缺页不得完成任务 |
| 引用页码覆盖率 | 100% | 每个节点必须可回到页面 |

扫描件没有原生文本时，文号、日期、金额、比例默认要求人工确认，即使模型输出形式正确。

## 文档解析门禁

- 原始文件、DocumentTree和派生Markdown三层关联完整。
- 解析器、OCR、分片器、模型和Prompt版本可追踪。
- 原生解析失败不得静默切换到非批准模型。
- 表格必须保留表头、单位、注释和页码。
- JSON DSL必须通过AJV/JSON Schema，不以OCR或Markdown结果替代。

## 评测集

- 国家、上海、广东、四川各建立政策问答与影响变化样本。
- 样本覆盖养老、失业、医保、补贴、有效期、地区覆盖和政策废止。
- OCR样本覆盖文本PDF、扫描PDF、混合PDF、复杂表格和关键数字。
- 评测输入、标注人、来源、版本和修改历史可追踪。

## 门禁失败处理

- 单个来源失败：隔离该来源，不阻塞已发布索引。
- 新索引低于旧索引：切回旧indexVersion并保存新索引供分析。
- OCR关键字段失败：暂停文档，不进入草案生成。
- 影响召回低于90%：只允许输出影响报告，不允许物化DraftBundle。
- 错地区或错日期非零：视为阻断级缺陷。
