## 1. 交付物

| 模块 | 端口 | 覆盖 queries.ts 写函数 |

### 1.2 事务助手

- `src/lib/db/index.ts` 导出 `withTransaction(fn)` 与 `DbClient` 类型：application 层开启事务并把事务内客户端传给仓储；抛错自动回滚（02.6 用例层接线使用）。

### 1.3 BLOCKER-001 显式修复 migration

- `drizzle/0001_align_showcase_cases.sql`（已登记 journal）：把 showcase_cases 物理结构对齐到声明式 Schema——DROP IF EXISTS transcript_text、ai_response/user_message SET NOT NULL、case_uid DROP NOT NULL、DROP 唯一索引、is_published SET DEFAULT true。
- **空库/演练库执行为 no-op**：应用 0001 后 schema 清单哈希与基线完全一致（`91882fc5…bb798`，实测）。
- **对生产 Neon 不执行**：生产迁移属暂停条件（需用户授权），且 transcript_text 存量数据需先导出保全——统一留待阶段07迁移演练路径。BLOCKER-001 的"显式 migration"要求已满足，"生产应用"挂起至阶段07。

### 1.4 集成测试（环境门控 `SSP_TEST_DATABASE_URL`）
