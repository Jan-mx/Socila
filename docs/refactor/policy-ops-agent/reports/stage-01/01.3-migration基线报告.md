## 2. 驱动决策（重要）

`drizzle-kit migrate` 对 postgresql 方言自动探测驱动：探测到 `@neondatabase/serverless` 即用其 websocket 连接，无法到达本地演练库，且该方言不支持 `driver` 覆盖。因此：

- 迁移**执行**改用 `scripts/run-migrations.mjs`（drizzle-orm 官方 `node-postgres/migrator` + `pg`），记账机制与 drizzle-kit CLI 完全相同（`drizzle.meta._journal.json`）。
- `pg`/`@types/pg` 以 **devDependency** 引入，仅迁移工具链使用；应用运行时驱动仍是 `@neondatabase/serverless`，运行时切换按计划发生在 Stage 02.4（CORE-FR-008），不违反阶段01非目标。
- 迁移**生成**（`drizzle-kit generate`）为离线操作，不受驱动影响。
