## 03.3 overlay 合并器（POL-FR-003～007）

`src/server/modules/policy/domain/overlay.ts`——纯函数合并器：

- 语义：同地区同键多版本 = **版本更替**（最新生效版本胜出，与 legacy `getEffectiveRules` 去重一致）；**跨包**同键 = 同级冲突；add 指向已存在键 = duplicate-add；replace/restrict/exempt 指向未知键 = unknown-key。
- 输出：有效实体集 + 逐实体 provenance（地区/包/版本/操作）+ 冲突清单；输入不可变。
- 测试（`overlay.test.ts`，7 项）：四操作语义、重复键冲突、未知键冲突、版本更替、跨地区隔离、asOfDate 过滤、属性式组合（结果唯一/顺序稳定/输入不变）。

## 03.4 冲突模型（POL-FR-008）

- migration 0005：`policy_conflicts`（地区、业务键、kind、成员版本 jsonb、状态 open/resolved/dismissed、resolution 审计字段）。
- 服务：`createPolicySnapshot` 遇冲突 → 冲突落库（open）+ `SnapshotBlockedError` 拒绝快照；`resolveConflict` 记录决策人/理由/前后状态。

## 03.5 不可变快照（POL-FR-009/010）

- migration 0005：`policy_snapshots`（uuid、resolved_path、content_hash、created_by）+ `policy_snapshot_members`（entity_type、business_key、payload、provenance，唯一约束）+ **BEFORE UPDATE/DELETE 触发器拒绝任何修改**（POL-AC-004 数据库层强制）+ `plans` 增加 `snapshot_id`/`resolved_jurisdiction_path`。
- 服务：`createPolicySnapshot` 在 `withTransaction` 中原子写入快照+成员；哈希 = 成员 canonical SHA-256；`getSnapshot`/`findLatest`。
