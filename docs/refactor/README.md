## 用途

本目录保存已经完成或正在进行的重大重构，包括计划、当前架构、进度、路线图、测试证据和历史归档。

## 归类规则

每个重构项目应包含：

- README：入口和阅读路线；
- REFACTOR-PLAN：已执行或待执行的重构计划；
- ROADMAP：未来开发方向；
- PROGRESS：当前真实状态；
- ARCHITECTURE：当前架构；
- TESTING：测试策略和命令；
- OPERATIONS：运行、部署和恢复；
- reports：执行证据；
- archive：历史计划和被替代文档。

历史证据不得因目录精简而删除。
