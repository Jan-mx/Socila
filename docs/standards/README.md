# 文档规范

> Author: Jan
> Status: Active
> Updated: 2026-09-01

## 用途

本目录保存全仓库通用的文档分类、元数据、状态和模板规范，不保存PolicyOps专属产品事实。

## 文件

| 文件或目录 | 用途 |
| --- | --- |
| `documentation-guidelines.md` | 文档创建、更新、归档和README状态规则 |
| `templates/` | PRD、Work Item、ADR、交接和验收模板 |

## 使用规则

- 新建文档前先阅读`documentation-guidelines.md`。
- 优先复用模板，不复制其他项目的实际内容。
- 项目专属事实写入对应项目目录。
- 通用规范不得包含真实密钥、个人数据或生产凭据。
- 修改本目录后，验收完成前必须将本README状态从`Updating`同步回`Active`。
