# 文档模板

> Author: Jan
> Status: Active
> Updated: 2026-09-01

## 用途

本目录提供可复制的文档骨架。模板只规定结构，不保存项目执行结果。

## 模板说明

| 模板 | 用途 |
| --- | --- |
| `feature-prd-template.md` | 大型功能或产品能力 |
| `work-item-template.md` | 中型开发任务 |
| `adr-template.md` | 重要技术或架构决策 |
| `acceptance-report-template.md` | 阶段或Work Item验收 |
| `handoff-template.md` | Agent或开发者交接 |

## 使用方式

1. 复制对应模板到目标目录。
2. 按`MM-DD-name.md`格式命名PRD，其他文档使用各自模板规定的格式。
3. 修改文件名和文档ID。
4. 将Author设置为Jan。
5. 创建时使用`Draft`状态。
6. 验收完成后同步状态和Updated日期。
7. 删除所有占位内容后再提交。
